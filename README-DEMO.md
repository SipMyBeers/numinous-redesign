# Numinous Designs — Website Demo

## Quick Start

1. Make sure you have **Node.js** installed (v18+): https://nodejs.org
2. Unzip this folder
3. Open a terminal in the folder and run:

```bash
npm install
npm run dev
```

4. Open your browser to **http://localhost:3000**

## What's Inside

- **Home page** (`/`) — Scroll-driven hero with portal zoom effect, laser lightshow, horizontal gallery, sketch-to-steel before/after showcase, and "Forge Defenders" arcade game teaser
- **Portfolio** (`/portfolio`) — Filterable project grid with lightbox and 3D model viewer, planets that zoom as you scroll
- **Services** (`/services`) — Service offerings breakdown
- **About** (`/about`) — Team and studio info
- **FAQ** (`/faq`) — Common questions + contact form
- **Forge Defenders** (`/game`) — Retro pixel art arcade game with WebGL lava background that changes color as difficulty increases. All enemies are inspired by Numinous sculptures!

## Game Controls

- Arrow keys / WASD to move
- Space / Z to shoot
- Touch to play on mobile

Enjoy!
